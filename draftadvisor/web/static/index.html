      ESPN (private leagues)

      How to find them: on espn.com, logged in, open the browser dev tools → Application (Chrome / Edge) or Storage (Firefox / Safari) → Cookies → espn.com and copy the values of espn_s2 and SWID (braces included). Public leagues need neither; the SWID also tells the page which team is yours. Cookies expire — paste fresh ones when ESPN starts answering 401.

      My ESPN league

      Which league is yours, kept here rather than in the draft form so it outlives the draft. The In-Season tab uses it directly — lineup, matchup odds, trades and waivers, no draft session needed. The League ID is the leagueId= number in your league URL; pasting the whole URL works too.
      Sent as X-Anthropic-Key / X-Access-Code (and X-ESPN-S2 / X-ESPN-SWID) headers on every request; never logged.
